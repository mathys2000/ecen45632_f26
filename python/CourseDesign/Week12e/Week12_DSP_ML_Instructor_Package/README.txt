Week 12 — DSP + Machine Learning

Files:
- Week12_DSP_ML_PCA_SVM_Trees_RF.pptx
  52-slide instructor deck containing Lecture 23, Lecture 24, weekly homework,
  weekly quiz, speaker notes, and an instructor solution appendix.

- notebooks/Lecture23_PCA_SVM.ipynb
  Executed Jupyter notebook: synthetic audio features, scaling, PCA, scree plots,
  loadings, linear/RBF SVM, GridSearchCV, and leakage-safe pipelines.

- notebooks/Lecture24_Trees_RandomForests.ipynb
  Executed Jupyter notebook: Gini/entropy, tree visualization, overfitting,
  cost-complexity pruning, random forests, OOB scoring, and feature importance.

- week12_audio_ml_demos.py
  Standalone Python version of the core demonstrations.

- synthetic_audio_features.csv
  Optional synthetic feature table. The notebooks also generate the data internally.

The data are synthetic and intended for teaching, so no external download is required.
