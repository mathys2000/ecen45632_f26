Below is a complete Python script that reads a WAV file, computes a Mel spectrogram and Mel-frequency cepstral coefficients (MFCCs), and plots both alongside the original waveform.

The script uses `librosa`, `NumPy`, and `Matplotlib`. It is suitable for experimenting with audio features in a DSP/ML course.

It performs the following operations:

1. Reads a WAV file and converts it to mono.
2. Resamples to 16 kHz if necessary.
3. Computes the STFT and power spectrogram.
4. Applies a Mel filter bank to obtain a 64-band Mel spectrogram.
5. Converts Mel power to decibels.
6. Computes 13 MFCCs from the log-Mel representation using a discrete cosine transform (DCT).
7. Displays the waveform, Mel spectrogram, and MFCCs, and optionally saves the figures and feature arrays.

## What the script computes

Audio waveform

\\(x[n]\\), sampled at 16 kHz

STFT and power spectrum

\\(|X[m,k]|^2\\)

64-band Mel filter bank

Weighted frequency-bin sums

Log-Mel power spectrogram

Power converted to dB

DCT-II

Retain the first 13 coefficients

MFCC feature matrix

13 coefficients per time frame

### 1. Mel spectrogram

The STFT is

\\[ X[m,k]= \sum\_{n=0}^{N-1} x[n+mR]w[n]e^{-j2\pi kn/N}. \\]

The power spectrogram is

\\[ P[m,k]=|X[m,k]|^2. \\]

For Mel filter \\(H\_\ell[k]\\), the band energy is

\\[ E[m,\ell] = \sum_k H\_\ell[k]P[m,k]. \\]

The script expresses the Mel energies in decibels:

\\[ S\_{\mathrm{dB}}[m,\ell] = 10\log\_{10} \left( \frac{E[m,\ell]}{E\_{\mathrm{ref}}} \right), \\]

with appropriate numerical flooring.

Here, `ref=np.max` sets the reference to the maximum Mel power in the recording. The displayed maximum is therefore 0 dB, and `top_db=80` limits the displayed dynamic range to 80 dB.

### 2. MFCC coefficients

The MFCCs are obtained by taking a discrete cosine transform (DCT) across the Mel-frequency dimension of the log-Mel representation.

Conceptually,

\\[ c_r[m] = \alpha_r \sum\_{\ell=0}^{M-1} S\_{\mathrm{dB}}[m,\ell] \cos\left[ \frac{\pi r}{M} \left(\ell+\frac12\right) \right], \\]

where \\(\alpha_r\\) provides orthonormal DCT scaling.

The interpretation is important:

- \\(c_0\\): Represents an average of the log-Mel spectral levels, subject to the reference and normalization convention.
- Low-order coefficients: Represent broad variations in the spectral envelope.
- Higher-order coefficients: Represent increasingly rapid variations across the Mel-frequency axis.

Retaining 13 coefficients reduces the feature dimension from 64 Mel bands to 13 cepstral coefficients per frame.

MFCCs are not simply selected Mel-frequency bands. Each MFCC is a weighted combination of all the log-Mel bands.

## Expected dimensions

With the default settings

\\[ f_s=16000,\quad N=512,\quad R=160,\quad M=64, \\]

a three-second recording contains 48,000 samples.

Because `center=False`, its number of frames is

\\[ T = 1+ \left\lfloor \frac{48000-512}{160} \right\rfloor =297. \\]

The resulting arrays have these dimensions:

| Representation  | Shape        |
| --------------- | ------------ |
| Waveform        | `(48000,)`   |
| One-sided STFT  | `(257, 297)` |
| Mel spectrogram | `(64, 297)`  |
| MFCCs           | `(13, 297)`  |

For CNN training, a channel dimension can be added to the Mel spectrogram:

```
mel_tensor = torch.tensor(    mel_db,    dtype=torch.float32).unsqueeze(0)
```

This gives `[1, 64, 297]`, which becomes `[B, 1, 64, 297]` after batching.

One final DSP distinction: the DCT in MFCC extraction is applied to the logarithmic Mel-band energies, not to the original waveform or directly to the complex STFT. It approximately decorrelates the spectral-envelope information and concentrates broad spectral structure into the lower-order coefficients.

For the audio classification CNN from Lecture 28, I would begin with the full 64-band log-Mel spectrogram. MFCCs are particularly useful as compact features for classical classifiers such as SVMs and random forests, or as inputs to smaller neural networks. Comparing both representations on the same recordings would make a useful course experiment.
